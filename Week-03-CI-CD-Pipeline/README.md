# Week 3: CI/CD Pipeline Basics

## Project Overview

This project demonstrates Continuous Integration (CI) using
GitHub Actions as part of the DecodeLabs DevOps internship.

## Objectives

- Understand CI/CD pipeline stages.
- Automate build validation.
- Execute automated tests.
- Verify the pipeline through GitHub Actions.

## Technologies

- Git and GitHub
- GitHub Actions
- Node.js
- JavaScript
- Node.js built-in test runner

## Pipeline Stages

1. Checkout: Retrieve the source code.
2. Build: Validate JavaScript syntax.
3. Test: Run automated tests.

## Run Locally

From this directory, execute:

    npm run build
    npm test

## Expected Result

The build should complete successfully, and all three
automated tests should pass.
