# Week 2 - Version Control with Git

## Objective
Learn Git and GitHub fundamentals for managing project
history and collaborating on software projects.

## Topics Covered
- Repository initialization and cloning
- Staging and committing changes
- Branch creation and merging
- Pushing and pulling changes
- Pull requests and code review

## Documentation
- [Git Commands](git-commands.md)
- [Git Workflow](workflow.md)

## Tools
- Git
- GitHub
- Visual Studio Code

## Learning Outcome
Understand how to track changes, maintain commit history,
and manage code using Git and GitHub.
